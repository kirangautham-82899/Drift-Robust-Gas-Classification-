# Raw data

Place `batch1.dat` ... `batch10.dat` here (they are git-ignored).

Source: UCI Machine Learning Repository, *Gas Sensor Array Drift Dataset*
(Vergara et al., 2012), DOI: 10.24432/C5RP6W.
https://archive.ics.uci.edu/dataset/270/gas+sensor+array+drift+dataset

Format: LibSVM, `label 1:v1 ... 128:v128`. Labels are gases 1-6.
Total: 13,910 samples across 10 chronological batches.
